Rust:
Rust is a modern programming language .

it is designed for performance , reliability and safety -especially safe handling of memory .

why learn rust?
1.one of the fast growing language 
2.learning rust make it easier to pick up other languages  like java python c++ and c# 
3. rust is very fast 
4. rust requires less memory compared to many other languages .
5.rust is used to build web servers , creating games , operating systems and much more !.

diff between rust and c/c++:
the main difference is that rust is safe by default .
in rust memory access is automatically  checked by the complier , which helps you avoid common bugs like crashes ,
leaks and unsafe memory behavior .
in c and c++ ypu must manually manage memory , which can lead to errors if you are not careful.
